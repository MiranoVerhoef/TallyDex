# TallyDex thumbnail handoff

Contains 839 primary card thumbnails and 48 My First Battle variant copies (887 image files).
Use manifest.json to map exact app card IDs to file paths and distinguish deck-stamp variants.
The variant copies include 34 primary fronts, so there are 14 additional distinct fronts.

Images are WebP, maximum height 480 px and quality 75, with transparent corners preserved.
These are for card grids/lists, not detailed zoom. All file SHA-256 values were checked.
No originals, detailed artwork, cached research or superseded stock images are included.
No app source or IPA changes have been made. Original scans remain safely on the owner's Mac.

Artwork remains copyrighted by its owners; this handoff does not grant redistribution rights.
